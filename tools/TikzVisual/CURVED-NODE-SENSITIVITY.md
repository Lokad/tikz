# Independent curved-node sensitivity

The trusted 28-node circle/ellipse corpus has a separate independent
calibration workflow. It writes fresh, hashed bundles under `artifacts/`
and grants no image admission. All reference engines and browser tooling
remain development dependencies.

Run from the repository root:

    node tools/TikzVisual/calibrate-curved-node-conformance.mjs
    node tools/TikzVisual/calibrate-curved-node-ink.mjs
    node tools/TikzVisual/curved-node-ink-self-test.mjs
    node tools/TikzVisual/trial-curved-node-conformance.mjs

The first producer consumes a fixed path and digest for the earlier
oracle-only PDF calibration. It verifies all original assets and sources,
checks the ordinary PDF cache, and runs a fresh framework-only native
reconstruction. No converter assembly, candidate scene or production font
resource supplies any geometry, frame, region or limit. The reconstructed
98 ink extents, camera and semantic SVG must reproduce the retained
independent evidence exactly. Native PGF paths, DVI positions, original
font inputs and outlined glyphs remain the measurement basis.

Primary observations cover twelve natural/expanded, 1x/4x,
transparent/white/black views. Primary limits are independently measured
per region and view, with only foreground means rounded upward to 1e-9.
PDF uses its measured native page origin and integer crop lattice. Original
SVG and the preselected native semantic six-decimal representation have
separate four-view policies; sensitivity shifts and other representations
provide no candidate allowance. The original 54 viewport controls remain
in the pinned source bundle.

Thirteen controls mutate only independent reconstructed SVG: missing
period/font glyph/border, doubled border, shifted glyph, opacity changes,
quarter-pixel shift, root cropping, ordinary/faint extra ink, faint border
loss, and ink outside the whole camera. Visible controls require both
frames and scales, with root cropping restricted to natural views. The
outside-camera control requires the natural PDF page gate; the primary
canvas and expanded PDF viewport intentionally cannot see beyond their
fixed camera. Numeric frame checks remain independently required.
Two controls change unpainted cap or solid phase state and preserve exact
pixels. Such states still require semantic numeric checks.

This stronger independent run retains a genuine sensitivity failure. A
one-percent opacity reduction on the period is rejected by primary pixels
but passes every old PDF limit at 1x in both frames. Its foreground mean
error decreases from 19.65 to 19.2 channel levels while all eight target
quantities remain within their ceilings. At 4x the old PDF policy rejects
it. Being closer to a different renderer does not establish correct ink.
The first command therefore returns one for this retained failure.

The follow-up producer consumes that explicitly selected failed bundle.
It adds integer per-channel ink sums over every fixed white-backed native
page crop, including samples below the edge threshold. Each actual sum
must exactly equal its independently measured native counterpart in that
same region/view. Original-SVG coverage has a separate policy. There is
no candidate fitting, blank-area averaging or extra margin. All original
error-limit rows, PNGs and native references remain unchanged.

The follow-up remeasures all retained control pages, replays four freshly
rendered native pages, and rerenders the faint period at both 1x frames.
PNG hashes, old metrics and new ink sums must agree exactly. Its report
retains all old paired images, each mutation, the original failed report,
new targeted crops, limits, renderer/source identities and exact tool
copies. Open `index.html` or inspect the paired paths in `report.json`.

The control suite rederives both policies, checks every region/RGB channel
against the new constraint, rejects malformed/missing ink and coverage,
and verifies manually authored faint RGB bitmap samples independently of
the SVG mapping. The original error-only acceptance and new rejection
remain explicit in the controls.

All 1,221 controls pass, including every required region/RGB channel. At 1x
the faded period's sums are 336 per channel against independently measured
native sums of 339; the unchanged ordinary-PDF sums are 352. The new check
rejects the loss in both frames while preserving the old ceilings.

The public prospective trial validates both complete independent bundles
and policies before invoking the converter. It requires 4,461 native
checks, 406 ink/root checks, twelve primary views with 1,188 whole/local
gates, and four PDF views with 408 gates on each SVG side. A fresh faded
public period is tested in all four PDF views. Source spans, scene,
provenance, paired images and differences remain in a fresh bundle. Eight
region crops per view are retained with explicit truncation metadata;
all 98 regions still have required measurements and gates. Failed regions
receive crop priority. The agent report links each failure to source,
crops and a trusted focused rerun such as:

    node tools/TikzVisual/trial-curved-node-conformance.mjs --crop-region glyph-22

The current public run passes native and frame checks and the original PDF
gate, but fails 4x primary and candidate PDF gates. The primary failure
includes the negative-separation circle and overlapping glyph crops.
The candidate differs from the fixed independent native ink signatures
in several 4x regions. These failures are retained; neither ceilings nor
ink constraints are fitted to the candidate. The next grounding step is
to investigate native-unit path serialization and independent compatible
representations before considering admission.

These local reports recorded one legacy calibration lock file with CRLF,
while Git stores its exact LF form. The source audit verifies both retained
raw bytes and the parsed/LF staged content and records this difference.
Immutable preparation must settle canonical source bytes before hosted CI;
the research reports are not claimed to be portable admission snapshots.

The first command returns zero only if all original expected sensitivity
outcomes pass; it currently returns one for the documented blind spot.
The follow-up and controls return zero for their stated research results,
one for an unexpected complete comparison result, or two for an incomplete
tool/input phase. An initial report-publication failure is also retained:
checks now retain only view tuples to keep evidence bounded.

These commands consume fixed local research evidence and are not the normal
cached CI admission gate. Immutable reviewed profiles, evidence corruption
controls, fresh public comparison/defect trials, broader node/label
interactions and hosted execution remain required. No other fixture family
inherits these limits or ink signatures.

The subsequent [path-unit experiment](CURVED-NODE-PATH-UNITS.md) varies
independent background representation while holding glyphs and framing
fixed. It reproduces the public failures without loading the converter;
the separate post-experiment diagnosis proves identical PNGs and metrics.
Native-unit calibration and sensitivity remain required before admission.
