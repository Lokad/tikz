# Primary node interaction policy

The `chromium-153-node-interactions-rgb-ink-v1` policy covers the three trusted
`state-paint`, `transforms`, and `colors` fixtures, totaling 41 rectangle nodes.
It uses the declared RGB profile, outlined Latin Modern labels, and independent
stroke-ink framing. It establishes a calibrated primary SVG match for these
fixtures. Ordinary PDF conformance and wider node/transform families remain
pending.

```text
dotnet run --project tools/TikzReference -c Release -- compare-node-interaction-primary
npm run test:interaction-primary --prefix tools/TikzVisual
```

The cached command needs the pinned browser and .NET, with no TeX or Poppler.
It accepts `--case` and `--out artifacts/...`; RGB/ink framing is fixed by this
profile. Each fresh public conversion first produces the original exact
comparison, retained as `exact-report.json` and `exact-suite.json`. The reviewed
runner then requires all native numeric checks, natural dimensions, global
image gates, and every independently calibrated region. The inspection gallery
is `artifacts/node-interaction-primary/index.html`. Failed regions retain paired
images, amplified differences, and source links.

## Evidence and limits

The [policy](interaction-profile.json) pins the unchanged oracle-only
[ink experiment](../../tests/Reference/NodeInteractionsRgb/calibration-ink.json)
and [regional experiment](../../tests/Reference/NodeInteractionsRgb/calibration-regions.json).
The former records 4,260 serialization/containment checks across native CSS and
fixed plus/minus-four-sp variants. The latter records 3,132 raw measurements
across 174 fixed glyph/path regions, three variants, two scales, and three
backgrounds. Original outlines, native measurements, and original paint/clips
provide this evidence; candidate code, resources, or failed images supply no
calibration data.

| Fixture | Maximum channel, /255 | Maximum foreground mean, /255 | Regions |
| --- | ---: | ---: | ---: |
| `state-paint` | 10 | 0.005928 | 38 |
| `transforms` | 32 | 0.026600 | 35 |
| `colors` | 43 | 0.006834 | 101 |

Global edge displacement allows one native raster pixel at each scale;
component counts must agree. Means round independent maxima upward to 0.000001
channel units. Each region has its own scale/background limits derived from
the same three independent variants. Region coordinates and one-CSS-pixel
padding are fixed before candidate inspection. The loader recomputes every
limit from the pinned measurements and verifies the unchanged comparator and
region-construction hashes. Limits cannot come from bundle input.

Natural width/height error allows 0.0002 CSS pixel, rounding the independent
frame experiment upward to 0.0001 CSS pixel. Native coefficients are exact;
frame/anchor/glyph origins retain the separate 1e-9-CSS-pixel checks. General
soft-path coordinates retain their declared numeric allowance. There is no
image alignment, coordinate fitting, or PDF resampling.

The reference retains original content and expands its viewport only to
contain independently measured polygon stroke ink. `original-driver.svg`,
original/native hashes, measurements, and frame provenance remain in every
bundle. Default-color and original-crop failures remain reproducible through
the separate exact commands; the policy does not change those baselines.

## Admission and failure paths

The [historical trial](../../tests/Reference/NodeInteractionsRgb/mutation-trial.json)
exposed both faint-content dilution and candidate transform precision errors.
The [native arithmetic repair](../TikzReference/TRANSFORM-PRECISION.md) and
[post-repair trial](../../tests/Reference/NodeInteractionsRgb/mutation-trial-after-transform.json)
pass all seven positive controls and reject all thirteen defects with the
original references and independent limits fixed. Paired transform images and
raw differences have been inspected. This evidence authorizes this scoped
primary policy; it does not supply an independent PDF allowance.

The [admission record](../../tests/Reference/NodeInteractionsRgb/primary-admission.json)
retains the three passing cases, raw global metrics, numeric/regional counts,
natural dimensions, reference/candidate hashes, renderer/tool identities, and
the completed policy checks. Full regional reports and paired images stay in
the ignored inspection bundles and are regenerated by the required commands.

The required thirty-one policy checks repeat those image controls/defects with
numeric checks bypassed, reject changed/missing calibration and widened policy
values, verify a numerical failure cannot pass with correct pixels, reject a
natural-height error, and reject empty numeric evidence, fitted registration,
and unapproved PDF input. Every image-only report identifies the bypass and
makes no semantic conformance claim. The candidate conformance comparison installs
all 174 pinned regions. Global metrics alone still accept the two faint losses.

Renderer identity pins Playwright, Chromium and its executable hash, browser
profile, Node, and Windows x64 distribution. Windows version remains recorded
in each report. Required cached CI checks are configured for Windows; hosted
execution and other distributions remain unverified. Future comparator,
reference, renderer, or scope changes require explicit evidence review.
