# Fixed curved-connection conformance

Run from the repository root with .NET 10, Node and the pinned development browser:

```text
node tools/TikzVisual/curved-edge-admission-self-test.mjs
node tools/TikzVisual/compare-curved-edge-conformance.mjs
```

The browser-free controls validate the immutable profile and its external
SHA-256 acceptance pin. The comparison owns a fresh [cached trial](CURVED-EDGE-CACHED.md)
and that exact trial's independent saved-image checker. No old research folders,
TeX command or PDF executable is needed. Every required source, native record,
qualification and policy is checked before conversion.

The [profile](curved-edge-profile.json) admits only five fixed curved `to`/`edge`
fixtures: 70 native paths, 66 paints, two clips, four nodes, 64 anchors, one named
coordinate and ten glyphs. All eight gates are required: 2,066 numeric checks,
471 frame checks, 4,728 primary checks, 1,636 checks on each original/candidate
PDF route, 1,596 exact native-page checks, 210 fresh primary defect views and
70 fresh PDF/native defect views. All 389 local regions remain required.

Limits come from the original independent qualifications, never candidate
images or errors. The unchanged original SVG driver needs no correction.
Primary and ordinary-PDF agreement are separately calibrated claims; zero-error
native pages compare against an independent SVG reconstruction, with full RGBA
equality. This does not claim that browser pixels equal ordinary PDF pixels.
The 18 image-only defects bypass numeric gates. Their 169 visible primary and
68 visible PDF views must reject in the target region. The 41 primary and two
PDF invisible views retain their explicit unchanged-image requirements.

The final stdout record names the exact completed report and its SHA-256:

```text
node tools/TikzVisual/curved-edge-admission-self-test.mjs --report artifacts/curved-edge-conformance/run-<id>/report.json
node tools/TikzVisual/curved-edge-agent-self-test.mjs --report artifacts/curved-edge-conformance/run-<id>/report.json
```

Read the report's `agent` object before opening images. It ranks all 6,224 local
observations by failed state, budget utilization, foreground error and changed
pixels, with a deterministic lexical tie break. Each record names its reference
route, exact integer raster rectangle, paired image paths, optional saved crops,
direct path/glyph/clip source span, source file and scene. Ranking and filtering
change presentation only. The detailed trial remains at `trial/index.html`.

Open the sibling `index.html` directly as a local file. Its 150 paired PNG inputs
are embedded as exact checked bytes, so canvas differences work without a local
server. Select a case, route or region; use integer zoom, synchronized scroll,
blink, overlay or the labeled RGB/alpha difference. Each displayed channel uses
the larger of its RGB error and the alpha error, so transparent black-stroke
loss stays visible. Separate raw channel/alpha differences remain
available through the primary artifact links. The source panel shows the source
text and original gate metrics. Every standalone PNG and JSON stays available
for a coding agent's image-viewing tool.

The inspection controls verify every region's raster containment and source
span, embedded image hashes, displayed samples against independently indexed
full PNGs, nearest-neighbor enlargement, empty-selection behavior, route filters,
blink/overlay, synchronized scroll and a visible image-only defect. They preserve
screenshots and a browser report with the exact input report digest.

The admission bundle copies the profile, acceptance pin, captured sources,
owned process logs, child reports and all trial/checker artifacts. Only a
completed admission report claims this fixed profile passed. Raw qualification,
trial, checker and control reports retain their original unapproved roles.
Failures retain pending reports and logs with no image-conformance claim.

`prepare-curved-edge-admission.mjs` explicitly verifies pinned lineage receipts
and writes an ignored candidate profile. Accepting it requires deliberate edits
to the tracked profile and external digest pin. Normal comparison cannot update
either, and rehashed replacement evidence does not authorize a policy change.

The exact recorded renderer includes the OS release. Same-host reproduction
does not qualify a hosted runner. Hosted execution, wider interactions, loops,
path labels, arrows and remaining TikZ coverage retain separate requirements.
All tooling is development-only; the production package depends only on .NET 10.
