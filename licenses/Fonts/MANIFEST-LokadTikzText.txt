The font data is embedded in the assembly and also distributed as JSON
alongside it under font-data/ in the NuGet package. The provenance and
font-profile manifest are distributed under font-data/ as well.
Independent reference fixtures under tests/Reference/Fonts/ are further
font-derived development data in the source repository, with the same
font license; they are not components of the shipped font-data work.

Changes from Latin Modern: six-font subset, EC/Cork encoding, JSON metrics,
flattened pair rules, SVG outline paths rounded to six decimal places.
Font faces and resource filenames use the distinct LokadTikzText name.
No original installed font file is replaced. No original font author's
support or endorsement is implied.

The complete original work, including Type 1 sources and metrics, is available:
  https://ctan.org/tex-archive/fonts/lm
  https://mirrors.ctan.org/fonts/lm.zip
  https://www.gust.org.pl/projects/e-foundry/latin-modern
