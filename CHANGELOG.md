# Changelog

## Unreleased — 0.1.0-preview.1 development

- Standalone .NET 10 TikZ subset to self-contained SVG, with source diagnostics,
  cancellation and shared work/output limits; no runtime package or native dependency.
- Paths, coordinates, affine transforms, scoped styles/paint/clips and measured
  rectangle/circle/ellipse nodes using bundled Latin Modern glyph outlines.
- Bounded straight/curved connections, path labels, arrows, positioning and
  calculated-coordinate library subsets.
- Single-argument styles, statement loops, numeric assignments, selected scalar
  functions, inline math/multiline labels and bounded sharp/smooth plotting.
- Scoped zero-argument token definitions, with lazy statement/value expansion,
  source provenance, cycle diagnostics and shared limits/cancellation.
- Modern arc radii follow option order, preserving eager shared-radius validation
  and the final independent axis assignments.
- Explicit nonzero/even-odd fill and captured clipping rules, with local clip-rule
  options rejected and independently grounded compound-contour image controls.
- Independent native/reference, primary/PDF and visible-negative comparisons for
  fixed fixtures and complete flowchart/network interactions. Fast iteration is
  separate from final qualification, with unchanged reference evidence reused.
- Development benchmarks for conversion phases, labels, startup/warm behavior,
  allocations, cancellation and resource-limit calibration.
- Current public contract and compatibility index linked from the README.

This is a development record, not a published-release announcement. Supported
syntax and qualification boundaries are in [SPEC](SPEC.md) and the
[compatibility index](docs/compatibility.md); general TeX/TikZ, arbitrary renderer
compatibility and broader hosted/release qualification are not established.
