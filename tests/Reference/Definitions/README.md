# Frozen definition references

The two trusted fixtures exercise the [bounded token-definition contract](../../../docs/DEFINITIONS.md):

- `definitions-contract`: lazy aliases, source order, scoped styles/definitions,
  a font-control boundary, statement/coordinate templates and foreach bindings.
- `flowchart-definitions`: measured positioned nodes, scoped widths/colors,
  statement calls, path labels, arrows and a calculated return coordinate.

`image-profile.json` pins byte-preserving native archives. They contain native
measurements, original backend SVG, unmodified PDF, independent glyph/path
encodings, per-view/per-region policies, visible-negative controls and independent
primary/PDF checking. No converter output defines a native pixel allowance.
The existing archive codec preserves canonical indices, hashes, bounds and ownership.

Run `node tools/TikzVisual/verify.mjs iterate --feature definitions` for affected
numeric/images, or `qualify` for the full final-source matrix. These restore frozen
references and check fresh returned SVG without invoking TeX. Native generation
accepts only pinned repository fixtures and is separate from the production library.
Qualification metadata retains its recorded scope; broader hosted/release
acceptance remains separate.
