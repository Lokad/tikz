# Independent curved-connection image evidence

`qualifications.json.gz` stores the complete native-only primary and PDF
qualifications and their independent saved-evidence checkers. All four original
report byte strings and every artifact digest remain unchanged. Deduplication
changes storage only; no public candidate output supplies an expected value.

The separate [native snapshot](../snapshot.json) and authored
[fixtures](../../../Fixtures/CurvedEdges) retain their original provenance.
Upstream fonts retain the attribution and redistribution terms in
[third-party notices](../../../../THIRD-PARTY-NOTICES.md); this cache does not
relicense font resources or generated references. Preparation scans every
decoded artifact for private host markers as well as the surrounding JSON.

See [portable trial instructions](../../../../tools/TikzVisual/CURVED-EDGE-CACHED.md).
The loader pins both digests and all four original report hashes outside the
archive. Loading bounds decompression, reconciles all required artifacts,
rederives image policies and checks current native/qualification sources before
conversion. These development fixtures stay outside the runtime assembly and
NuGet package. Their roles remain unapproved; immutable admission is separate.

The [fixed-family consumer](../../../../tools/TikzVisual/CURVED-EDGE-CONFORMANCE.md)
requires a separately pinned profile, fresh owned public evidence and its exact
independent checker. It preserves this archive's original roles and bytes.
