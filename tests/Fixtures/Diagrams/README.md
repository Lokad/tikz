# Complete diagram targets

These repository-authored fixtures drive the next positioning/path-label work.
They are acceptance targets, not claims of current compatibility. Each combines
measured node labels, positioning, arrows and calculated coordinates; the network
also uses curved connections and sloped labels, and the transformed flowchart
requires active-frame arithmetic and transformed node/glyph placement.

Run them through the public converter first and preserve actual diagnostics or
numeric/image failures. Implement the blocking requirement before expanding the
corpus. Native reference generation may consume these trusted sources; arbitrary
unsupported input is tested only against the converter.

Completion requires independent node/label/anchor and path/arrow measurements,
fixed framing, primary whole/local images, both SVG-versus-ordinary-PDF routes,
source-linked inspection and explicit unsupported/limit controls for all three
diagrams. Reuse existing artifact/process/report handling and generic controls;
retain separate native registration and semantic checks where they differ.
Existing calc or arrow family admission does not qualify these interactions.
